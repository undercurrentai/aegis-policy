# Verifier-kit CI dependencies — SOURCE file for requirements-verify-ci.txt.
#
# The lockfile compiled from this file is installed by the `verifier-kit` job
# in .github/workflows/tests.yml: the job that actually RUNS the 19
# tests/test_verify_action.py tests (marker `needs_aegis_sdk`) — including the
# guard proving AEGIS_KEYS_DIR_OVERRIDE / AEGIS_POLICY_PATH_OVERRIDE are
# ignored without AEGIS_INTERNAL_FIXTURE_MODE.
#
# SEPARATE from requirements-dev.txt for the same reason requirements-aux.txt
# is: the pytest matrix job's venv deliberately excludes the SDK so the
# deselection marker stays an honest capability statement, and the SDK's
# dependency tree (liboqs-python et al.) has no business in the fast matrix
# legs.
#
# The SDK pin is EXACT (==, not >=): the committed fixtures must be proven
# against the pinned version — bump deliberately, with the fixtures
# re-verified, never via range drift. The 1.0.0→1.4.0 bump (2026-07-30) was
# exactly that: DSSE wire format documented byte-identical since 1.0.0,
# `_verify_local` drift since the vendored ref proven formatting-only, and
# the 19 fixture tests re-run green against the 1.4.0 wheel BEFORE the bump.
# NB: action.yml's consumer-facing default is its own contract surface (bumped
# to 1.4.0 in v1.5.0, kept equal across both declaration sites by
# TestSdkDefaultParity) — this CI pin and that default move independently.
#
# Regenerate the lockfile whenever this file changes (a drift guard in
# tests/test_workflow_invariants.py fails until you do):
#   pip install pip-tools
#   pip-compile --generate-hashes --strip-extras \
#     --output-file=requirements-verify-ci.txt requirements-verify.txt

# The verifier kit itself — public PyPI since 2026-05-15 (roadmap task #59).
# 1.4.0 carries the [verify] cryptography range >=48.0.1,<49 (GHSA-537c-gmf6-5ccf
# fix — Dependabot alert #1); released 2026-07-30 specifically to unblock this pin.
aegis-governance[verify]==1.4.0

# Test runner + YAML for the test module itself (same bounds as
# requirements-dev.txt).
pytest>=8.0,<10
PyYAML>=6.0

# bundled OpenSSL in cryptography wheels < 48.0.1). Unsatisfiable until

# <47 to >=48.0.1,<49; the SDK's own range now implies this, but the floor
