# The lockfile compiled from this file is installed by the three workflows
# whose tooling does NOT belong in the test venv: lint.yml (yamllint +
# PyYAML), aegis-shadow-eval.yml (httpx), resolve-callee-parity.yml (PyYAML).

# Each job installs the union; surplus packages in a lint venv are harmless,
# a missing stub in the test venv is not.
#
# Regenerate the lockfile whenever this file changes (a drift guard in
# tests/test_workflow_invariants.py fails until you do):
#   pip install pip-tools
#   pip-compile --generate-hashes --strip-extras \
#     --output-file=requirements-aux-ci.txt requirements-aux.txt
